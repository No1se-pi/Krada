# Игровой цикл

Материал → рейд → проверка знания → серверная награда → развитие героя/школы → новое испытание. MVP содержит один вопрос по истории и шесть конфигурируемых классов. Класс меняет будущий стиль взаимодействия, но не корректность ответа и не величину награды. Учебный результат хранится отдельно от игровых характеристик.

Расширение выполняется через typed registries классов, способностей, эффектов, противников и рейдов. Никакой пользовательский Python/JavaScript из конфигурации не исполняется. Визуальная сборка должна быть чистой функцией `(seed, generator_version, asset_pack_version)`, не влияющей на силу.
