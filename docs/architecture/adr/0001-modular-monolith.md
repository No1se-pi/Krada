# ADR-0001: модульный монолит

Статус: принято. Контекст: небольшая hackathon-команда и будущий рост до многих школ. Рассмотрены микросервисы, монолит без границ и модульный монолит. Выбран последний: одна транзакция защищает критический сценарий и снижает ops-стоимость, а доменные пакеты/события сохраняют seam для выделения. Пересмотр при независимых командах, профилях масштабирования или SLA модулей.
